Installation guide

This guide shows how to install the service on one machine. You need Docker and a free port for the API. The installation takes about ten minutes.

Before you start

Check that Docker is running. Copy the example environment file and set the dashboard key. The key protects the API, so do not use the example value.

Start the services

Run the compose file from the project folder. The command starts the database, the object storage, the search index, the migrations, the worker and the API. The API listens on port 5080.

Check the installation

Open the dashboard and sign in. Request a crawl of a small site. When the first pages show in the list, the installation works.
